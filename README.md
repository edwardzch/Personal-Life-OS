# Personal Life OS 使用教程

一个简洁高效的个人效率工具，支持手机和电脑多端使用。

---

## 🚀 快速开始

### 1. 启动应用

```bash
cd c:\Users\zhangch64\Desktop\RecordingTools
.venv\Scripts\activate
python app.py
```

启动后会显示：
```
已创建默认用户: admin / admin123
 * Running on http://127.0.0.1:5000
```

### 2. 访问应用

- **电脑端**: 打开浏览器访问 `http://127.0.0.1:5000`
- **手机端**: 确保手机和电脑在同一网络，访问 `http://你的电脑IP:5000`

### 3. 登录

使用默认账号登录：
- 用户名: `admin`
- 密码: `admin123`

> ⚠️ **安全提示**: 首次登录后请修改 `app.py` 中的默认密码

## 📝 功能模块

### 速记流 (Memos)

快速记录碎片化想法，支持 Markdown 格式。

| 操作 | 电脑端 | 手机端 |
|------|--------|--------|
| 新建速记 | 顶部输入框，`Ctrl+Enter` 发送 | 顶部输入框，点击发送按钮 |
| 添加标签 | 在标签栏输入，逗号分隔 | 同左 |
| 删除速记 | 点击卡片右侧垃圾桶图标 | 同左 |

**Markdown 支持**:
- `**加粗文字**` → **加粗文字**
- `- 列表项` → 显示为列表
- ``` `代码` ``` → 显示为行内代码

---

### 稍后读 (Bookmarks)

收藏有价值的网页链接，告别"存了不看"。

| 操作 | 说明 |
|------|------|
| 添加收藏 | 粘贴 URL，标题自动获取 |
| 标记已读 | 点击 ✓ 图标 |
| 归档 | 点击 📦 图标 |
| 筛选 | 点击顶部标签：全部/未读/已读/归档 |

---

### 提醒 (Reminders)

设置定时提醒，支持浏览器桌面通知。

| 操作 | 说明 |
|------|------|
| 创建提醒 | 输入标题 + 选择日期时间 |
| 标记完成 | 点击左侧圆圈 |
| 查看已完成 | 勾选"显示已完成" |

**通知设置**: 首次使用时浏览器会请求通知权限，请点击"允许"以接收到期提醒。

---

### 搜索

全局搜索速记和收藏内容，输入关键词即可。

## 📱 响应式设计

| 设备 | 导航方式 |
|------|----------|
| 电脑 (≥768px) | 左侧固定侧边栏 |
| 手机 (<768px) | 底部导航栏 (类似微信) |

**手机端优化**:
- 底部导航栏避开键盘
- 单列卡片布局，易于滚动
- 触摸友好的按钮尺寸

## ⚙️ 自定义配置

### 修改默认密码

编辑 `app.py` 第 218 行：
```python
user.set_password('你的新密码')
```

然后删除 `instance/app.db` 文件，重新启动应用。

### 修改监听端口

编辑 `app.py` 最后一行：
```python
app.run(debug=True, host='0.0.0.0', port=8080)  # 改为 8080 端口
```

## 🔧 常见问题

**Q: 如何在手机上使用？**
1. 确保电脑防火墙允许 5000 端口
2. 在手机浏览器输入 `http://电脑IP:5000`
3. 可添加到主屏幕作为 App 使用

**Q: 数据存储在哪里？**
数据库文件: `instance/app.db` (SQLite 格式)

**Q: 如何备份数据？**
复制 `instance/app.db` 文件即可完整备份。
